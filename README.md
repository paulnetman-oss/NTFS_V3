# NTFS Suite v3.0

Aplicación modular para análisis y administración controlada de matrices NTFS.

## Módulos

1. **Generar matriz**: reservado hasta aprobar el catálogo ACL.
2. **Analizar ACL**: funcional. Agrupa combinaciones reales, frecuencia y ejemplos.
3. **Comparar matrices**: funcional. Cliente y escaneo lado a lado, diferencias amarillas.
4. **Planear cambios**: funcional en simulación. Lee únicamente celdas `#FFFF00`.
5. **Aplicar permisos**: bloqueado deliberadamente en v3.0.

## Reporte del Analizador ACL

- RESUMEN
- COMBINACIONES DETECTADAS
- EJEMPLOS
- SIN CLASIFICAR
- RUTAS

La aplicación no modifica permisos NTFS.
